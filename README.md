# ESP32 RC Car Controller 🎮

This project is the wireless controller for the ESP32-CAM RC Car.

It sends movement commands to control the RC car.

---

## Features

- 🎮 Joystick control
- 📡 Wireless communication
- ⚡ Low latency commands
- 📱 Mobile compatible UI

---

## Hardware Used

- ESP32
- Joystick module
- Push buttons
- Battery pack
